# Metadados do arquivo .exe (aba "Detalhes" nas propriedades do Windows).
#
# Sem isto, o executável nascia sem NENHUMA informação — nome, empresa,
# versão — nem no Explorer, nem para o Windows Defender/SmartScreen, que
# tratam um .exe "anônimo" com mais desconfiança do que um com essas
# informações preenchidas (não resolve sozinho, mas ajuda). Gerado com
# PyInstaller (pyi-grab_version/pyi-set_version usam este mesmo formato).
#
# O número de versão aqui é fixo (não lido de VERSAO.txt) de propósito:
# o arquivo é montado ANTES do PyInstaller rodar, e a mudança automática
# do número a cada versão publicada exigiria reescrever este arquivo
# lendo VERSAO.txt na hora do build — mais uma peça pra quebrar sem
# necessidade, já que este número só aparece na aba "Detalhes" do
# Windows, nunca na tela do programa (que usa a leitura de verdade,
# `atualizador.versao_atual()`, feita de dentro de VERSAO.txt).
